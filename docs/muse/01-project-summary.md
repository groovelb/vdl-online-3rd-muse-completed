# MUSE

> 디자이너와 바이브 코딩 유저를 위한 레퍼런스 기반 디자인 토큰 추출 도구

## 배경 및 목적

- **문제**: AI에게 레퍼런스 이미지를 그대로 넘기면 일관성 있는 결과가 나오지 않음
  - 사람은 레퍼런스를 볼 때 "이 프로젝트엔 이 컬러만 참고" 같은 선택적 판단을 함
  - AI는 그런 선택적 판단 없이 이미지 전체를 뭉뚱그려 해석
  - 결과물이 디자이너 의도와 다른 방향으로 흘러감
- **해결 접근**: 2단계 구조로 해결
  - (1) 프로젝트에서 꼭 필요한 요소를 먼저 정의
  - (2) 그 기준으로 레퍼런스를 토큰화해 AI가 쓸 수 있는 형태로 정리
- **기대 효과**
  - Cursor, Claude Code 등 바이브 코딩 도구에 바로 투입 가능한 토큰 산출
  - 디자이너의 의도가 반영된 일관된 결과물
  - 레퍼런스 아카이빙 + 프로젝트 단위 큐레이션 경험 통합

## 핵심 기능

| # | 기능 | 설명 | 우선순위 |
|---|------|------|---------|
| 1 | 레퍼런스 아카이빙 | 드래그앤드롭/링크로 이미지 저장, 인피니트 그리드 뷰 | 필수 |
| 2 | 레퍼런스 자동 태깅 | 아카이빙 시 AI가 컬러톤/스타일/카테고리 등 태그 자동 부여 | 필수 |
| 3 | 프로젝트 생성 | 아카이브에서 이미지 선택 + 이름/의도/유형 입력 | 필수 |
| 4 | 자동 토큰 분석 | 선택된 레퍼런스를 AI가 컬러/타이포/레이아웃/그라디언트/키비주얼로 분해 | 필수 |
| 5 | 토큰 확인 및 조정 | 레이어별 결과 확인, 불필요 요소 제거, 중요 요소 강조 | 필수 |
| 6 | 토큰 내보내기 | MUI theme 형식으로 export | 필수 |
| 7 | 레퍼런스 자동 추천 | 프로젝트 이름/의도 기반으로 아카이브에서 어울리는 레퍼런스 추천 | 선택 |
| 8 | 프로젝트 유형 프리셋 | 랜딩/대시보드/모바일/브랜드 유형별 분석 가중치 | 선택 |

## 대상 사용자

- **주요 사용자**
  - 디자이너: 레퍼런스를 구조화해 디자인 방향을 정리하고 싶은 사람
  - 바이브 코딩 유저: AI 코드 도구에 일관된 디자인 입력을 주고 싶은 사람
- **보조 사용자**
  - PM/기획자: 비주얼 방향을 팀에 전달할 산출물이 필요한 사람

## 기술적 범위

- **포함**
  - 웹 기반 인터페이스 (미니멀 UI)
  - 이미지 업로드·링크 저장, 인피니트 그리드
  - AI 기반 토큰 분석 (컬러/타이포/레이아웃/그라디언트/키비주얼)
  - 레이어별 토큰 편집 UI
  - MUI theme 형식 export
- **제외**
  - 실제 코드 생성 (토큰 export까지만, 컴포넌트 코드는 외부 바이브 코딩 도구가 담당)
  - 협업/공유 기능 (초기 범위 아님)
  - 모바일 네이티브 앱
  - MUI 외 다른 테마 포맷 (Tailwind, Chakra 등은 추후 고려)
- **제약사항**
  - AI 분석은 외부 모델 API 의존 → 비용/지연 고려 필요
  - 타이포 분석은 이미지에서 추정 기반 (정확한 폰트명 매칭은 best-effort)
  - 이미지 저장소 용량 전략 필요 (초기: 로컬/브라우저 저장 범위에서 시작 가능)

## 성공 기준

- 프로젝트 하나 생성 → 토큰 export까지 3분 이내
- export된 MUI theme을 프로젝트에 바로 적용해 시각적 일관성 체감 가능
- 토큰 조정 UI에서 레이어별 의도 반영이 직관적으로 이루어짐
- 유저가 자유롭게 레퍼런스를 수집하면 자동으로 태깅되고, 프로젝트 생성 시 의도에 어울리는 레퍼런스가 자동 탐색·추천됨
